# Cisco Networking Labs

A collection of networking practice projects created while studying routing, switching, and CCNA-level concepts with **Cisco Packet Tracer**.

> **Status:** Learning collection. Individual labs will be documented as their topology files, screenshots, and verification notes are ready.

## Goals

- Practise network design and configuration.
- Understand switching, VLANs, routing, and network services.
- Build confidence with CLI configuration and troubleshooting.
- Keep reproducible lab files and explain the reasoning behind each configuration.

## Topics covered in the learning work

The portfolio learning work has included practice with:

- VLANs and inter-VLAN routing
- DHCP and DNS
- Static routing and OSPF
- EtherChannel
- Access Control Lists (ACLs)
- NAT/PAT and GRE concepts
- Network verification with show and ping commands

These topics describe the learning scope; each lab should include its own evidence before being presented as a completed implementation.

## Lab documentation standard

Each lab should include:

1. **Objective** — what the topology is intended to demonstrate.
2. **Topology** — a screenshot and a short device/interface description.
3. **Addressing** — IP addressing table and VLAN information, where applicable.
4. **Configuration** — relevant commands or configuration exports.
5. **Verification** — ping tests and relevant show-command output.
6. **Troubleshooting** — issues encountered and how they were resolved.
7. **Learning notes** — what the lab demonstrates and what could be improved.
